# CodeForces Solutions in Python & Algorithmic Theory

Bienvenido/a a este repositorio. Aquí encontrarás una colección de soluciones a diversos problemas de **CodeForces** implementadas en **Python**, acompañadas en su mayoría de su **análisis de complejidad temporal **, además de una sección de **fundamentos teóricos** tanto matemáticos como informáticos.

---

## ¿De qué trata este repositorio?

Este proyecto está concebido como un recurso de consulta, estudio y comparación para cualquier persona interesada en la programación competitiva, algoritmos y estructuras de datos. 

Cada ejercicio propuesto representa una **posible solución funcional**, sirviendo como punto de referencia para analizar diferentes enfoques de resolución, optimizaciones y estilos de código.

---

## Estructura del Repositorio

El contenido se organiza de manera clara en dos ejes principales:

### 1. Ejercicios Resueltos (`/solutions`)
- **Lenguaje:** Python 3.
- **Análisis de Complejidad:** La mayoría de los problemas incluyen la notación *Big-O* para tiempo ($O(N)$, $O(N \log N)$, etc.) .
- **Enfoque Práctico:** Soluciones estructuradas pensando en claridad, legibilidad y eficiencia.

### 2. Base Teórica (`/theory`)
Sección dedicada a conceptos fundamentales que facilitan la resolución de problemas complejos:

- **Teoría de Programación & Algoritmos:**
  - Estructuras de datos (Listas, Tuplas, Diccionarios, Graph Representation, Heap/Priority Queue).
  - Algoritmos clásicos (Búsqueda binaria, Dos punteros, Ventana deslizante, Programación Dinámica, BFS/DFS).
- **Fundamentos Matemáticos:**
  - Teoría de números (GCD, LCM, Criba de Eratóstenes, Modulo Arithmetic).
  - Combinatoria, geometría básica y propiedades numéricas aplicadas a competencias.

---

## ¿Para quién es este repositorio?

- **Estudiantes y Competidores:** Que buscan preparar competencias de programación competitiva (ICPC, CodeForces contests, etc.).
- **Desarrolladores/as:** Que desean reforzar sus bases de lógica de programación, algoritmos y análisis de algoritmos.
- **Autodidactas:** Que necesitan ejemplos resueltos en Python con explicaciones teóricas de respaldo.
